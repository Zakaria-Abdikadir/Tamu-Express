# 🧾 Tamu Express

Tamu Express is a simple order management web app built with **HTML, CSS, JavaScript**, and **Firebase**.  
Deployed on **Render**.

## Features
- Customers can place orders easily.
- Orders are stored in Firebase Firestore.
- Admin login for viewing placed orders.
- Live order updates in real-time.

## Tech Stack
- Frontend: HTML, CSS, JS
- Backend: Firebase Firestore
- Deployment: Render
